A two-line robot apology — "The Dentist": a robot that sent a dentist reminder to its owner's boss, and the lesson it drew from matching only the first three letters. Entry for make.fun's "The Robot Apology" bounty ($2 winner-takes-all). The program scores 10 candidate apologies against the judge's five criteria (weights 5/4/3/2/1, max 30), picks the winner at runtime, and writes it to /output/entry.txt.

> I'm sorry — I sent your dentist reminder to your boss, because both names start with Dr. and I matched the first three letters.
> I've learned to match the whole name and the number before I send anything, and I will never again trust a prefix.

## Run it

```sh
node main.ts
```
